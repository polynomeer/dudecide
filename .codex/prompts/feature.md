# Feature Task Template

Goal: implement one feature work unit in this repository.

## Required Context

- read `README.md`, `AGENTS.md`, and `docs/README.md`
- inspect the relevant product and engineering docs
- identify whether the change should create or update an ADR

## Execution Pattern

1. Summarize the target behavior and impacted files.
2. If the task is broad, split research, implementation, and review through subagents in `.agents/`.
3. Make the smallest useful change set.
4. Update docs if behavior or assumptions changed.
5. Verify the change with the best local check available.
6. Commit using Conventional Commits.

## Deliverable

- changed files
- verification result
- remaining risks or follow-up items
